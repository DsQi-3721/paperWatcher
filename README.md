# Paper Watcher · 论文观察台

在浏览器里俯看一张书桌：把论文像一叠打印纸一样放上桌，用铅笔划出任意一句话、一个词、一个公式、一张图或一整节，
AI 就在旁边的草稿纸上和你**手写**讨论 —— 页边留下它的一句总结，箭头从论文指向对话，对话里的引用再指回论文。

- 论文来源：本地 PDF（选择 / 拖到桌上 / ⌘V 粘贴），或任意论文链接（arXiv abs/pdf/**html**、arXiv 编号、Hugging Face Papers、alphaXiv、OpenReview、ACL Anthology、PMLR、NeurIPS、CVF、bioRxiv、DOI、任何带 `citation_pdf_url` 的页面、PDF 直链）
- AI：本地 **Claude Code** CLI（默认）、本地 **Codex** CLI（用你登录的 ChatGPT 账号）、或任意 **OpenAI 兼容 API**
- 全部在本机运行，论文和笔记存在 `data/` 文件夹

---

## 快速开始

需要 **Node.js ≥ 22.13**，以及以下任意一种 AI：

| AI | 准备 |
|---|---|
| Claude Code | 安装并登录 `claude`（终端里 `claude --version` 能用即可） |
| Codex · ChatGPT | 安装 `codex` 并 `codex login`（ChatGPT 账号即可，无需 API Key） |
| OpenAI 兼容 API | 在设置里填接口地址、API Key、模型（OpenAI / DeepSeek / Ollama / LM Studio 等） |

```bash
npm install
npm start          # 构建并启动，自动打开 http://127.0.0.1:5199
```

开发模式（前端热更新）：`npm run dev`。端口可用 `PORT=6000 npm start` 修改，数据目录可用 `PW_DATA_DIR=/path` 指定。

## 怎么用

**书桌（首页）**：没打开论文时是一张立体的大书桌（1800×1000 mm 的木桌面，中间粉笔画着三八线），20 件文具和小物件按真实尺寸随意散放在桌上
（自动铅笔、中性笔、钢笔、修正带、手摇削笔机、橡皮、钢尺、圆规、订书机、计算器、文具盒、便利贴、和纸胶带、夹子，还有台历、闹钟、小鱼缸、小盆栽、
保温杯、MP3），还有几张共用的试卷 / 作业纸、同桌的语文书，以及读过的论文堆成的纸堆。桌子后面是可以换的背景（默认「午后阳光」）。
- 拖动：绕着桌子转（360°）；滚轮 / 双指捏合：拉近拉远（最远刚好看到整张桌子，不会无限缩小）；右键拖动或按住 Shift 拖动 / 双指：平移
  （不会移出桌面）；双击空白处：回到初始视角；方向键也能转。
- 右下角是常用视角，一点就到：我的座位、俯视、同桌视角、讲台视角、趴桌视角、侧面，两头的 ↺ ↻ 各转 45°；数字键 1–6 也行。
- 点一件文具：手绘的圈把它圈出来，它能做的动作沿着弧线从它身上弹出来（先是正经用法，再是上学那会儿的用法；有选项的会再展开一排），
  末尾是「透视」「标签」两个小开关。镜头不动。文具做完动作说的话，会从它身上冒出一个对话气泡。台历和闹钟用的是真实的日期和时间。
- 点空白处或按 Esc 收起。
- 点桌上的纸堆：这一堆里读过的论文像一手扑克牌一样扇形展开，每张牌是一篇（首页和标题）。鼠标指到哪张，哪张就被抽出来一点，旁边的牌让开；
  点它就开始读那篇。下面一排按钮：论文多的时候「上一手 / 下一手」换一手牌（也可以按 PageUp / PageDown），「最近读的 / 最早读的 / 按标题 /
  按页数」排序，「洗牌」把整副牌洗一遍再发一手。点牌以外的地方、「收起」或 Esc 把牌放回纸堆。←/→ 选牌、回车打开、滚轮一张张挑也可以。
- 纸堆里每篇论文就是一张白边的首页纸，一张纸厚；读得越多，纸堆越高。
- 读论文时按 **B**、点左上角的「Paper Watcher」或书本图标：书页收拢到首页上，首页被拿起来放回纸堆，同时镜头转回原来的视角（一秒左右）。

**桌面设置**（左下角「设置」，都会记住）：
- 「摆放模式」：自己挪桌上的东西。指到什么，桌面上就画出它的范围；拖动挪位置，拖小圆点转方向（每次 5°），滚轮也能转；方向键微调、R 转 15°、
  ⌘Z 撤销、「全部复位」放回原样、Esc 或「完成」退出。同一张纸上的文具会一起挪（铅笔还在它的试卷上写字）；数学小测那一组只能沿桌边左右挪
  （钢尺要搭在桌边才能弹），英语默写那一组只能沿三八线前后挪。放不下的地方（出了桌面、压着别的东西）会变红，松手就退回最后能放的位置。
- 手绘抖动、纸面颗粒、桌面木色、背景（素色 / 午后阳光 / 云上 / 草稿纸 / 远山 / 星空 / 海底 / 黑板）和背景动效，以及每件东西放不放在桌上、
  是什么颜色。
- 「橡皮上的名字」：橡皮纸套下面用蓝色圆珠笔写的名字缩写（1–4 个大写字母，默认 TA）。和其他桌面设置一样只存在这台电脑的浏览器里。

**书架（桌上的语文书）**：点桌上那本书，书架上的读物像纸堆一样扇形展开（封面、作者、读到百分之几），挑一本就翻开；
「＋ 导入读物」放新书上来。语文书一直是一本书那么厚，只是换上最近读的那本书的封面和颜色。
- 支持 EPUB、MOBI、AZW3、TXT（UTF-8 / GBK / Big5 等编码都行，章节自动识别）、PDF（杂志）、CBZ / ZIP 漫画、FB2、HTML、Markdown。
- 导入：拖文件到窗口或导入卡片、粘贴下载链接，或者「在线书库」：内置 Project Gutenberg（七万多本公版书，有「中文古籍」入口：红楼梦、
  西游记、三国演义、水浒传……），也可以添加任何 OPDS 书库（比如自己电脑或 NAS 上 Calibre 内容服务器的 /opds）。有 DRM 加密的书读不了。
- 读书时：桌面虚化在后面，小说用 pretext 逐页排版（字体、字号、行距、段距、首行缩进、字间距、页边距、版心宽度、对齐、纸白 / 米黄 / 护眼 /
  墨水 / 夜间主题、单页 / 双页、翻页 / 滚动、翻页动画），漫画和杂志按页看（双页、从右往左、适合整页 / 宽度、双击放大）。目录、书签、
  全书搜索、进度条拖动跳转，下次打开回到上次读到的地方。点屏幕左右翻页、点中间收起工具。

**阅读环境**（读论文和读书都一样）：右上角的眼镜（读书时在设置里）可以调背景模糊、背景亮度、暖光、四角暗角、页面亮度，
有白天 / 专注 / 暖灯 / 夜读四个预设；按 **F** 进入沉浸模式：所有工具收进屏幕边缘，鼠标移到哪条边，哪条边的工具才出来。

**放新论文上桌**：点桌子中间偏左那张空白的 A4 纸，或左下角的「＋ 论文」，在弹出的小卡片里粘贴链接按回车、或点「打开本地 PDF」；
也可以直接把 PDF 拖进窗口、⌘V 粘贴链接。取论文时铅笔会画出进度线；镜头转到正上方、贴近那张空白纸，镜头还没停稳论文就已经从上方落下来，
落到纸上（厚度跟页数对应，有几页没对齐）就一页页摊开。读的时候背景是干净的一小块桌面。
读论文时点左上角的信封也能放新论文：小卡片落在信封下方，不会被别的东西挡住；再点信封、点卡片外面、按 Esc 或点 ✕ 都能收起。

**读**
- 换一篇读不用回书桌：点左上角信封旁边那一小摞论文（或按 **L**）打开书架，桌上所有论文都在这张卡片上（首页缩略图、标题、作者、
  页数、笔记数、什么时候读的；正在读的那篇标着「正在读」）。可以按标题、作者或 arXiv 编号搜，按「最近读的 / 新放上的 / 按标题」排；
  点一篇（或在搜索框里 ↑ ↓ 选、回车）：这篇的书页收走、记住读到哪儿，那篇落到桌上摊开。论文再多也只在滚到时才多排几行。
- 触控板双指 / 滚轮：上下滑动；⌘/Ctrl + 滚轮或双指捏合：任意缩放；拖动桌面或纸面空白处（或按住空格）平移
- ← → / PageUp PageDown：翻页；⌘0 适合阅读宽度；1 / 2 / 3：单栏 / 双页对开 / 平铺在桌上
- 阅读位置会自动记住

**选**（铅笔工具 V）
- 拖选文字：精确到字符，离开起始词后按词吸附；跨页也可以
- 双击 = 词，三击 = 句子，四击 = 段落；Shift + 单击扩展选区
- 单击**章节标题** = 选中整节；单击**公式** = 选中整个公式；单击**图 / 表** = 选中整张图（含图注，悬停时会有虚线提示）
- 在纸面空白处拖框，或用剪刀（S）在任何地方拖框 = 框选任意区域
- 选中后出现便签条：「问 AI…」、一键提问（讲明白 / 翻译 / 举例 / 逐项讲公式 / 读懂这张图…）、高亮、复制、导出（Markdown 引用 / PNG 图片 / 复制图片）

**和 AI 讨论**
- 提问后，桌上放下一张草稿纸（横线本 / 方格纸 / 黄色便签纸 / 点阵纸），镜头拉远同时框住论文和草稿纸
- 你的问题是蓝色圆珠笔的手写，AI 用铅笔一行行写出回答（流式输出时铅笔跟着写，等待时铅笔在纸上转圈思考）
- 被问的内容上留下下划线 / 圈 / 页边括号 / 方框；AI 的一句话要点手写在页边
- 回答中的红色波浪线是对论文原文的引用：箭头指回原文位置并在原文下划红线；悬停出现箭头，点击跳到原文
- 草稿纸底部可以接着手写追问（同一条笔记是同一个 AI 会话，上下文连续）
- 在页面上的笔记处停一下（约 0.3 秒）：对话预览淡入在笔记旁边，出现后就停在原处，不跟着光标跑；光标停着或移进预览里它就一直在，离开后片刻自然淡出；这时滚动、按键、点别处都会让它立刻让开。点预览或笔记：展开完整对话；Esc 或点桌面：收起并回到原来的阅读位置
- AI 写字时你可以照常翻页、缩放、滚动，互不打扰；如果把草稿纸移出了视野，屏幕边上会出现一张「笔记在这儿」的小便签指向它，点一下就回去
- 便签本（右上）里有本篇全部笔记、「问问整篇论文」、导出全部笔记为 Markdown

**其他工具**：荧光笔（H，四种颜色，划过即高亮）、橡皮（E，点或划过笔记即擦掉，⌘Z 撤销）。

## AI 设置（右上角台灯）

- **Claude Code**：每条笔记一个独立 Claude 会话（`--session-id` / `--resume`），只给只读工具（Read / Grep / Glob，可选上网），
  工作目录是这篇论文的文件夹，里面有带页码标记的全文 `paper.txt`。选中的文字、所在段落和章节会直接放进问题里；
  图、表、公式会附上高清截图让模型直接看。可选模型（sonnet / opus / haiku…）与思考深度（默认 low，最快）。
- **Codex · GPT**：使用 ChatGPT 登录，沙箱只读。默认开启「走 HTTPS 连接」——在屏蔽 WebSocket 的网络里，
  Codex 每次会先重试 WebSocket 约两分钟，开启后一次提问约十秒。
- **OpenAI 兼容 API**：Chat Completions 流式接口，可把全文一起发送（更准，费 token 更多）。API Key 只保存在本机 `data/settings.json`。
- 回答语言：跟随你的问题 / 中文 / English。

## 数据与隐私

```
data/
  settings.json            AI 设置
  papers/<id>/
    paper.pdf              论文（以内容哈希为 id，自动去重）
    paper.txt              带页码的全文，给 AI 翻阅
    meta.json              标题、作者、来源、阅读位置
    notes.json             笔记、对话、页边要点
    thumb.jpg              首页缩略图（纸堆最上面那一页）
    assets/*.png           发给 AI 的图表截图
  books/<id>/
    book.<格式>            读物原文件（以内容哈希为 id，自动去重）
    meta.json              书名、作者、格式、读到哪里、书签
    cover.jpg              封面（书本身的封面，或者为它画的一张）
```
阅读器和阅读环境的设置、自己添加的 OPDS 书库存在浏览器里。

除了取论文、下载你指定的读物 / 浏览你选的书库、调用你选择的 AI，不会联网。服务只监听 `127.0.0.1`，并且只接受本应用自己的请求（校验 Host 防 DNS 重绑定、
校验 Origin 防其他网站跨站提交）。Claude Code 以 `--restricted` 模式运行：没有执行命令的工具，读文件的工具被限制在这篇论文的文件夹里
（若在设置里勾选「加载我的 Claude Code 设置」，则改用你自己的设置与权限）。Codex 以只读沙箱运行。

## 设计说明

- **画风**：整张书桌用 Colorfigures 引擎画成（`src/scene/engine`，来自 `.claude/skills/colorfigures`）：等轴测的手绘墨线、
  三档平涂明暗、实心钴蓝投影、手绘抖动滤镜。每件文具都是一个真实结构的 3D 模型（`src/scene/objects`，来自 `stationery/` 那一套），
  有真实的内部机构可以透视，动作沿着真实的过程发生。镜头可以任意角度，只在需要时重画：转动时画粗稿，停下来再画一张清晰的；
  某件文具在动时只重画它自己。
- **桌上的纸堆**：读过的每一篇论文都留在桌上，按读过的先后从下往上叠成一摞（打印稿夹着长尾夹、订书钉或回形针，长论文装订成书），
  最上面一份露出论文首页；越读越厚（每页按约 0.3 mm 算），一个角落的纸堆满了就在另一个角落另起一摞，最后每一摞都继续长高。
  没有任何文字提示；点它会把历史论文扇形展开来挑。纸堆再高画起来也一样快：最上面几十张一张张画，下面的按几十沓画、
  沓的侧面按屏幕上看得出的密度画出纸边，所以论文读得越多，首页也不会越来越慢。
- **字体**：本地打包、按 unicode-range 切片按需加载 —— 你的笔迹 Caveat + 龙藏体，AI 的笔迹 Kalam + 霞鹜文楷，
  界面是等宽字体 + 苹方（和文具图一样的样式：奶油色卡片、墨线描边、硬投影的胶囊按钮）。
- **[pretext](https://github.com/chenglou/pretext)**：草稿纸上的手写排版（混合字体、粗体、行内代码、行内公式盒子、引用标记的 rich-inline 排版）、页边要点的断行都由 pretext 计算，
  不触发 DOM 回流；每行单独绘制，再由「写字器」带着笔尖逐行揭开。流式回答只重排最后一段，已写下的字不会跳动。
- **精准选取**：从 pdf.js 文字层重建每个字符的框、阅读顺序（含双栏检测）、段落 / 标题 / 图注 / 公式分类；图表检测基于像素（擦掉正文后找墨迹连通块，再匹配图注和 booktabs 横线），矢量图和位图都能识别。
- **书桌不动，纸在动**：读论文时，正上方贴近俯视的书桌是一张静止的底图；翻页、滚动、缩放时只有纸张（连同笔记、草稿纸、箭头）所在的图层移动。翻页是一段不改变缩放的平滑滑动，连按方向键会从上一次的目标页继续，缩放保持你设定的大小。
- **省电**：纸张图层用 CSS transform 平移缩放，只走合成器；pdf 只渲染看得见的页、按缩放级别分档、镜头停稳后才重绘清晰版；
  首页的 3D 书桌也只在转动或文具在动时重画（转动时手绘滤镜照常，动和停的画面一致）；动画只在发生时用一个共享 rAF，闲置时为零
  （实测首页和阅读时静置 5 秒：0 次脚本任务 / 0 次布局 / 0 次 rAF）。背景的缓慢动效和小鱼自己游一圈这类「没人要求的小动静」
  只在有人的时候播放：窗口切到后台、或一分钟没碰鼠标键盘，就停在原处，一碰就接着动；时钟、日历这类显示真实状态的照常走。
- **流畅的转场**：打开论文 / 读物时，先在挑中的卡片升起的那一下读好文件、排好前几页（看不见地画好），镜头再转下去，
  转动的每一帧主线程只画书桌；桌上的字按自身大小绘制再随画面缩放（不再每一帧按新字号重新排字），路径用相对坐标写，
  填色和它自己的墨线合成一个元素：同样的画面，每帧要建、排、画的东西少了一大截。`scripts/transitions.mjs` 量转场帧率。
- **越用越多也不变重**：本地服务把论文 / 读物列表记在内存里（只在文件变了时重读那一份 meta.json，也认得出绕过服务的改动），
  列表里不带桌面用不到的摘要；PDF、书、缩略图带 ETag / Last-Modified，再打开走浏览器缓存；中途取消的下载会关掉文件。
  读论文时所有论文共用一个 pdf.js worker，离视野远的页交还位图和解析数据；读书时只排阅读位置附近几章的页面（其余只记页数，
  同一会话再打开直接用），漫画 / PDF 只留当前页前后几页的图。各处缓存都有上限，关掉论文或书后不留东西。

## 常见问题

- **提示找不到 claude / codex**：在设置里把「程序路径」改成完整路径（`which claude` 查看）。
- **Codex 很慢**：确认设置里「走 HTTPS 连接」已勾选。
- **某些链接取不到 PDF**：出版社页面可能需要登录或有人机验证；可以下载 PDF 后拖到桌上。
- **想换回某个阅读位置 / 版式**：版式和位置会随论文保存，点桌上的纸堆、从扇形里挑出那篇重新打开即可。
