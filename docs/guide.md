# 使用指南

[← 回到首页](../README.md)

## 启动与 AI 设置

需要 Node.js ≥ 22.13。第一次运行 `npm install` 安装依赖，再运行 `npm start`，浏览器会打开本机阅读器。

首页点「AI」，阅读时点右上角台灯，选择连接方式：

| 方式 | 设置 |
|---|---|
| Claude Code | 安装并登录 `claude`，可以选择模型和思考深度 |
| Codex | 安装 `codex`，运行 `codex login`；模型留空时跟随 Codex 配置 |
| OpenAI 兼容 API | 填接口地址、API Key、模型名，再选择 Chat Completions 或 Responses |

找不到 CLI 时，把「程序路径」改为完整路径，可以用 `which claude` 或 `which codex` 查看。
Codex 连接很慢时，检查「走 HTTPS 连接」选项；它适用于使用 ChatGPT 登录、WebSocket 连接不通的情况。
使用自己的 API 网关时，可直接选择「OpenAI 兼容 API」，填写地址并选择对应协议。

回答语言可设为跟随问题、中文或 English。API 模式可以附带全文，方便模型联系上下文，也会使用更多 token。

## 导入论文

- 直接把 PDF 拖进窗口，也可以点「＋ 论文」或阅读界面左上角的信封，选择本地文件。
- 粘贴论文链接或 arXiv 编号后按回车，也支持 `⌘V` / `Ctrl+V` 粘贴导入。
- 支持 arXiv、Hugging Face Papers、alphaXiv、OpenReview、ACL Anthology、PMLR、NeurIPS、CVF、bioRxiv、DOI、PDF 直链，以及带 `citation_pdf_url` 的页面。

有些出版社页面需要登录或验证，取不到时可以先下载 PDF，再拖进阅读器。扫描版 PDF 需要先做 OCR，才能使用依赖文字的搜索和选词功能。

## 阅读、选取和做笔记

滚轮或触控板双指上下滚动；按住 `⌘` / `Ctrl` 滚动可以缩放。拖动纸面空白处或按住空格拖动，可以平移页面。
按 `1`、`2`、`3` 切换单栏、双页和平铺，阅读位置会自动保存。

铅笔工具（`V`）用来选取内容：

- 拖选文字，支持跨页；双击选词，三击选句子，四击选段落。
- `Shift` + 单击可以扩展选区。
- 点章节标题可选整节；点识别到的公式、图表可选中对应区域。
- 用剪刀（`S`）拖框，可以选任意区域。

选好后，点「问 AI」输入问题，或使用翻译、解释、举例等快捷提问。
对话会留在旁边的草稿纸上，可以继续追问。回答中的引用可以点击，跳回论文对应位置。
阅读时点右上角常驻的「论文笔记」或按 `N`，可以查看本篇笔记、问问整篇论文、导出 Markdown；沉浸模式下这个入口仍然可见。

荧光笔（`H`）直接高亮，橡皮（`E`）擦除笔记，`⌘Z` / `Ctrl+Z` 撤销擦除。按 `M` 暂时隐藏笔记，`Esc` 收起选区或对话。

## 英语笔记

首页点「英语笔记」或桌上的笔记本，阅读时点左上角带 **Aa** 的绿色本子。

### 从论文里选词

1. 打开「从论文收集」，选择论文。
2. 输入目标数量。也可以写一个学习目标，例如“机器学习专业术语”或“表达对比和局限的句子”。
3. 点「AI 选词」，完成后勾选想留的内容，再点「加入词本」。

单词、短语和句子都有双语解释、原文例句与译文。原句会先与论文文字核对；如果符合条件的内容不够，会说明实际找到的数量。

进度区显示已用时间、已核对数量和最近完成的内容。「×」只收起进度；「取消生成」停止任务，已经核对好的候选项仍可收藏。
成功加入词本后，进度区会自动收起。

### 阅读时随手收藏

选中英文后点「加入词本」，AI 会补充解释和例句并保存。
也可以先点「翻译」，再在对照页面的英文原文中划选、收藏；未重新划选时会收藏整段。
原文选区对应的 AI 对话纸上，也有「Aa」收藏入口。

### 复习和整理

相同英文会合并并累计收集次数，不同来源的例句会保留。词本支持搜索、按类别和学习状态筛选，以及按最新收集或收集频率排序。
点「记住了」移入已记住分类，也能改回学习中；删除后可以撤销。
点例句下的来源，回到对应论文查看上下文。

## 全文搜索

按 `⌘F` / `Ctrl+F`，或点阅读工具栏的放大镜，搜索当前论文。匹配处会高亮，输入框旁显示结果数量。
`Enter` 跳到下一处，`Shift+Enter` 跳到上一处，`Esc` 关闭；也可以勾选区分大小写或完整单词。

## 论文书架与垃圾桶

首页点纸堆，可以翻看读过的论文。阅读时按 `L` 或点左上角的论文堆，打开列表换一篇读。
列表支持标题、作者、标签等搜索，也能在所有论文的正文里查找。可按状态、领域、年份等分组，或多选后批量贴标签、删除。
「自动整理」会为 arXiv 论文补充缺失的领域和年份。

删除需要连续确认两次，论文会先进入垃圾桶，可以连同笔记和阅读位置一起恢复。
30 天后会自动清除文件，也可以手动清理；清理后保留来源和笔记等记录，重新导入同一文件时可恢复。
「抹掉记录」会进一步删除这条记录。正在阅读的论文不能直接从书架删除。

## 读书和在线书库

首页点桌上的书，再点「导入读物」。支持 EPUB、MOBI、AZW3、TXT、PDF、CBZ / ZIP 漫画、FB2、HTML 和 Markdown；不支持 DRM 加密文件。

可以拖入文件、粘贴下载链接，或在「在线书库」里搜索 Project Gutenberg。也支持添加 OPDS 书库，例如自己的 Calibre 内容服务器。
字体、字号、行距、主题、单双页和滚动方式都可以调整；目录、书签、全文搜索和阅读进度会在阅读界面中提供。

## 桌面和阅读环境

首页拖动空白处旋转视角，滚轮缩放，右键或 `Shift` + 拖动平移。双击空白处回到初始视角，也可以用右下角的视角按钮。
点文具可以查看它的动作；点空白处或按 `Esc` 收起菜单。

左下角「设置」可以改木色、背景、动效和文具颜色。「摆放模式」里，拖动移动物件，拖圆点旋转；`R` 转动 15°，`⌘Z` / `Ctrl+Z` 撤销，`Esc` 退出。

阅读时点右上角眼镜，调整背景模糊、亮度和暖光。`F` 切换沉浸模式，工具栏会收进屏幕边缘。

## 每日待办、英语默写与音乐

**每日待办**：点桌上的手账本，或首页的「待办」。输入一项内容后按回车添加，勾选完成；已有内容可以直接编辑，离开输入框后保存。输入、条目和桌上预览都用「问 AI」里自己的手写字体。左边可切换最近 30 天的日期，删除支持撤销。桌上的本子显示当天前三项和完成状态；更早的数据仍留在文件中。

**英语默写**：点英语默写纸、按动笔菜单里的「写听写」，或首页「默写」。默认取词本里最近收集的 10 个单词或短语，也可调节本轮数量。看中文提示写英文，或点「听发音」后填写。提交后显示对错，拼错时给出正确拼写；忽略大小写、空白和句末标点，保留单词内部的连字符和撇号。

发音使用浏览器和系统的英语声音，默认优先选用 Samantha 等普通音色，跳过已知的特殊音效声。可以切换声音、试听，选择正常或慢速；选择会保存在当前浏览器中。「停止朗读」或关闭默写本都会停止发音。

词本新增、删除或更新后，桌上的默写纸会同步；「刷新最新词条」开始新一轮练习。句子不加入拼写题，答题记录单独保存，不会自动把词本条目标为“已记住”。

**MP3**：点播放器菜单中的「音乐库」，或首页「MP3」，导入本地音频或添加音频直链。支持播放/暂停、上一首/下一首、音量、拖动进度和单曲循环，机身上的按键也会控制真实播放。关掉音乐库面板或进入论文阅读后仍可继续听，右下角有小播放器。

本地音频每个文件最多 200 MB，按内容去重，支持浏览器能解码的 MP3、WAV、M4A、OGG、FLAC、AAC 等格式。直链需要直接返回音频；网易云、汽水等平台的歌单网页不能直接作为音频播放。刷新后保留曲库和音量等偏好，需要手动再次播放。

「移出」只移出音乐列表，可以撤销；导入的本地音频保存在数据目录中，原文件不会被移动。

## 快捷键

| 快捷键 | 作用 |
|---|---|
| `V` / `H` / `S` / `E` | 铅笔 / 荧光笔 / 剪刀 / 橡皮 |
| `Enter` | 就选区提问；搜索框中跳到下一处 |
| `←` / `→`、`PageUp` / `PageDown` | 翻页 |
| `↑` / `↓` | 滚动 |
| `⌘0` / `Ctrl+0` | 适合阅读宽度 |
| `⌘` / `Ctrl` + `+` 或 `-` | 放大 / 缩小 |
| `1` / `2` / `3` | 阅读时切换单栏 / 双页 / 平铺 |
| `⌘F` / `Ctrl+F` | 搜索论文 |
| `⌘C` / `Ctrl+C` | 复制选区 |
| `⌘Z` / `Ctrl+Z` | 撤销擦除 |
| `T` / `M` | 目录 / 隐藏或显示笔记 |
| `N` | 论文笔记 / 问问整篇论文 |
| `L` / `B` | 书架 / 回到书桌 |
| `F` / `?` | 沉浸模式 / 快捷键说明 |
| 空格 + 拖动、`Esc` | 平移 / 收起 |

首页数字键 `1`–`6` 对应六个常用视角。读书时的快捷键以读书界面的提示为准。

## 数据、备份与端口

默认数据目录是项目下的 `data/`：

| 位置 | 内容 |
|---|---|
| `settings.json` | AI 设置和 API Key |
| `english-notebook.json` | 英语词本、例句、来源和学习状态 |
| `planner.json`、`dictation.json` | 每日待办与默写检查记录 |
| `music.json`、`music/` | 音乐列表、音频直链和导入的音频文件 |
| `papers/<id>/` | PDF、提取的文字、缩略图、笔记和阅读位置 |
| `books/<id>/` | 电子书、封面、书签和阅读进度 |
| `trash/` | 删除后的文件或清除记录 |

备份整个数据目录即可。API Key 保存在本机，界面只显示遮掩后的值；不要公开数据目录。
桌面摆放、阅读环境和自己添加的 OPDS 书库等偏好保存在浏览器中。

AI 问答和选词会按功能需要，把问题、选区、图片或论文文字发送给所选 AI 服务。
Claude Code 默认使用受限的只读工具，Codex 使用只读沙箱；加载自己的 Claude Code 设置会改变其权限配置。
本地服务默认监听 `127.0.0.1`，并校验 Host 和跨站写入请求的 Origin。

更改端口或数据目录（macOS / Linux）：

```bash
PORT=6000 npm start
PW_DATA_DIR=/path/to/library npm start
```

开发模式、构建命令和代码结构见 [开发说明](development.md)。
