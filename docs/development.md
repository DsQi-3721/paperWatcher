# 开发说明

[← 回到首页](../README.md) · [使用指南](guide.md)

## 运行与检查

需要 Node.js ≥ 22.13。

```bash
npm install
npm run dev        # 前端热更新
npm run typecheck
npm test
npm run build
npm run serve      # 运行已构建的版本
```

`npm start` 会先构建、再启动服务并打开浏览器。端口和数据目录分别由 `PORT`、`PW_DATA_DIR` 指定。

## 代码结构

| 目录 | 职责 |

| `src/desk/`、`src/pdf/` | 阅读布局、镜头、PDF 渲染、文字与图表选取 |

| `src/english/` | 英语词本界面、生成进度和搜索文本处理 |
| `src/ui/`、`src/library/` | 工具栏、全文搜索、书架、标签、设置和筛选 |

| `tests/` | 纯逻辑与本地服务测试 |
| `scripts/` | 截图、交互流程和性能测量工具 |

## 实现要点

- **书桌与图标**：书桌使用 Colorfigures 引擎，文具模型来自 `stationery/`。墨线、三档明暗和钴蓝投影由几何绘制；工具栏图标复用同一套材质与光照规则。
- **PDF 选取**：通过 pdf.js 的文字信息重建字符框和阅读顺序，再识别段落、标题、图注与公式。图表检测结合页面像素、图注和表格横线。
- **手写对话**：[pretext](https://github.com/chenglou/pretext) 负责混合字体、公式和引用标记的排版。流式回答按行显示，引用通过文字位置连回论文。
- **字体**：手写效果使用 Caveat、龙藏体、Kalam 和霞鹜文楷。字体在本地打包，按需加载。
- **英语词本**：生成时逐项核对原句，存储双语解释、论文 ID、页码和例句。重复收藏按英文合并；进度显示实际核对数量，取消后保留已完成候选项。
- **全文搜索**：归一化大小写、空白、连字和断行连字符，同时保留到原字符位置的映射，用于高亮。

## 渲染与缓存

阅读时，书桌是静止背景，纸张和笔记通过 CSS transform 平移、缩放。PDF 只渲染附近页面，远离视野的位图会释放；论文之间共用 pdf.js worker。

书桌主要在视角变化或文具动作时重绘。持续背景动效在窗口进入后台或长时间无操作后暂停。
论文与读物列表通过元数据缓存减少磁盘读取，PDF、缩略图等文件使用 ETag 和 Last-Modified。
电子书按阅读位置附近的章节排版，固定页面读物只保留当前页附近的图像。

`scripts/` 中保留了转场、场景和空闲状态的性能测量工具，修改这些部分时可按需检查。
